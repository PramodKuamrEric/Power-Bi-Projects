# 🛒 E-Commerce Analytics Dashboard

The dashboard shows total net sales of approximately 340.28M with 81.84M total profit and a 24.05% profit margin. Sales increased by around 0.77% YoY, while total orders declined by approximately 1.19%. At the same time, AOV is around 57.06K, indicating that the increase in sales may be supported by higher value per order. Repeat customers are around 1K, which provides an important customer-retention KPI. Electronics is the leading category, while Audio is the leading subcategory. Rajasthan and Maharashtra are among the strongest states by sales contribution, and Debit Card is the highest payment method by sales in the displayed data.

## 📊 Project Overview

This project is an **E-Commerce Analytics Dashboard built using Microsoft Power BI**.

The objective of this project is to transform raw e-commerce data into meaningful business insights related to:

- Sales
- Profit
- Orders
- Customers
- Products
- Returns
- Sellers
- Targets
- Payment Methods
- Geographic Performance
- Year-over-Year (YoY) Growth

The dashboard is designed from an **Executive / Business Analytics perspective** to help management monitor company performance and make data-driven decisions.

## 📈 Dashboard Analysis

The dashboard provides analysis of:

- Monthly Sales Trends
- Category & Subcategory Performance
- State & City Performance
- Payment Method Analysis
- Customer & Repeat Customer Analysis
- Profitability
- Target Performance
- Returns

## 🎯 Business Objective

The main objective of this project is to help a company understand its overall e-commerce performance.

The dashboard answers important business questions such as:

- What is the total Net Sales?
- What is the total Profit?
- How many orders were placed?
- What is the Profit Margin?
- What is the Average Order Value (AOV)?
- How many Repeat Customers are there?
- Which categories generate the highest sales?
- Which cities and states perform best?
- Which payment methods generate the most sales?
- How are Sales, Orders and Profit growing compared with the previous year?
- What are the MTD, QTD and YTD sales?
- How much of the sales target has been achieved?
- Which products or categories have high return activity?

# 🗂️ Data Model

The project contains multiple tables:

| Table | Purpose |
|---|---|
| Calendar | Date and time intelligence |
| Customers | Customer information |
| Orders | Order-level sales and profit data |
| Order_Items | Product-level order transactions |
| Products | Product and category information |
| Returns | Returned order information |
| Sellers | Seller information |
| Targets | Sales target information |

The data model follows a **Star Schema** approach.


### Key Insights
